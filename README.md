# 📊 Sales Analysis Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Sales Analysis Dashboard built using Microsoft Power BI**.

The dashboard helps analyze sales performance across different markets, customers, products, and time periods. The goal is to transform raw sales data into meaningful insights using interactive visualizations and KPIs.

## 🚀 Dashboard Features

### 💰 Revenue Analysis
- Revenue breakdown by market
- Comparison of revenue across different cities
- Monthly revenue trends
- Identification of high-performing markets

### 📦 Sales Quantity Analysis
- Sales quantity by market
- Comparison of sales volume across markets
- Identification of high and low-performing markets

### 👥 Customer Analysis
- Top 5 customers based on revenue
- Customer-wise revenue comparison
- Identification of major revenue contributors

### 🛍️ Product Analysis
- Top 5 products based on revenue
- Product-wise revenue comparison
- Identification of high-performing products

### 📅 Interactive Filters

The dashboard provides interactive filters for:

- Year
- Month
- Time period

These filters allow users to explore the sales data dynamically.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Visualization** – Charts, cards, slicers and interactive reports

## 💡 Key Insights

The dashboard can be used to identify:

- Markets generating the highest revenue
- Markets with the highest sales quantity
- Major revenue-generating customers
- Top-performing products
- Revenue trends over time
- Differences between revenue and sales quantity

## 🎯 Project Objective

The main objective of this project is to demonstrate how **Power BI can be used to analyze sales data and convert it into actionable business insights** through interactive dashboards and visualizations.
